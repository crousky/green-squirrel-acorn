# HiveReader

## Hosting Change

The HiveReader service is now hosted at a path-based approach at `/hive-reader` instead of a subdomain.

## Kindle Email Configuration

The Kindle email configuration has been moved to the `/hive-reader` page. Please set up your Kindle email preferences there.

## User Authentication

For security reasons, users will be prompted to log in if they are not authenticated when accessing the `/hive-reader` page.
